# 个人炒股交易系统 使用手册

一套你自己的交易系统：**思想沉淀 → 交易记录 → 纪律复盘 → 个股问询**。
默认完全离线运行、数据不出本机；也可以一键开启**云端同步**——电脑关机后手机照样记账复盘，多设备自动合并数据。

---

## 一、快速开始（30 秒）

1. 把整个 `stock-system` 文件夹拷贝到电脑任意位置（桌面、D 盘均可）；拿到的是 `stock-system.zip` 就先解压到任意目录。
2. 用 **Chrome 或 Edge** 双击打开 `index.html`。
3. 首次打开会自动载入一套演示数据（示例规则、示例交易、示例复盘），先随便点点看懂流程。
4. 确认要正式启用后，到「设置」点 **清空全部数据**，从零开始沉淀自己的体系。

> 断网状态下所有功能（含 AI，若已配置本地模型）均正常可用。

### 两种使用方式，按需选择

| 方式 | 适合谁 | 电脑关机后能用吗 | 手机能用吗 |
|---|---|---|---|
| **纯离线**（双击 `index.html`） | 只在自己电脑上用 | ❌ 电脑关机即停 | 需电脑开着并连同一 WiFi |
| **云端同步**（见「部署指南.md」） | 想随时随地记账复盘 | ✅ 数据在云端 24 小时在线 | ✅ 手机浏览器直接用 |

> 云端部署约 10 分钟，免费方案详见文件夹里的 **`部署指南.md`**，跟着做即可，无需任何编程基础。

## 二、系统怎么用（核心闭环）

### 第 1 步：思想库 —— 把课件沉淀成规则

- **原始素材**：把老师课件的关键段落、群内观点、直播笔记原样贴进来（标题、来源、日期）。
- **提炼为规则**：点素材卡片上的「提炼为规则」，把它变成一条可执行的纪律，填写：
  - 类别：买入条件 / 卖出条件 / 仓位管理 / 风控纪律 / 心态与流程
  - 权重 1-5：影响个股问询评分；**权重 ≥4 的"风控纪律"拥有一票否决权**
  - 状态：试验中 → 已验证 / 已废弃（随复盘数据迭代调整）
- 每次编辑规则都会**自动保存历史版本**（点「版本历史」查看），老师的思想演进轨迹完整留痕。

### 第 2 步：交易台账 —— 记录每笔交易

点「+ 记一笔交易」，填写代码、方向、价格、股数、费用、**买卖理由（必填）**、下单情绪、计划止损/目标价，并**勾选这笔交易所依据的规则**。

系统自动计算：摊薄成本、当前持股、每笔已实现盈亏、总盈亏、胜率。卖出数量超出持仓会被拦截。

### 第 3 步：复盘中心 —— 用纪律检验每笔交易

对每笔交易逐条对照：「这条规则，当时实际执行了吗？」（符合 / 违反 / 不适用），再写教训与改进动作。系统自动生成：

- **四象限**：正确（赚纪律内的钱）/ 侥幸（赚钱但违纪）/ 可接受（亏钱但守纪）/ 错误（亏钱且违纪）
- **纪律执行度**总览与每条规则的违反率
- **守纪时胜率 vs 违纪时胜率**：守纪胜率明显高于违纪 → 规则升"已验证"；反之 → 迭代或废弃该规则

> 这就是"结合指导思想对买卖理由复盘 + 思想不断迭代"的落地方式。

### 第 4 步：个股问询 —— 随时评估一只股票的可交易性

输入代码，对每条启用中的规则勾选当前状态（符合 / 不符合 / 不确定），系统按权重打分：

- **A · 可交易**（≥75 分）：满足主要条件且未触碰风控红线
- **B · 谨慎观望**（50-74 分）：条件不完全满足，建议观察
- **C · 回避**（<50 分或触发一票否决）：触碰权重 ≥4 的风控纪律时直接否决

每次评估可存档，回看自己对同一只股票判断的变化。补充说明栏写走势、量能、消息面观察——填表本身就是盘感训练。

## 三、可选：接入本地 AI（完全离线的智能问答）

个股问询页的「AI 深度分析」可接入本机 Ollama 大模型，把你的全部指导思想作为上下文回答问题。

### 方式一：一键脚本（推荐，自动完成全部步骤）

双击运行文件夹里对应你系统的脚本：

| 系统 | 脚本 | 说明 |
|---|---|---|
| Windows | `一键配置AI助手-Windows.bat` | 双击运行 |
| macOS | `一键配置AI助手-macOS.command` | 双击运行；若提示无法验证开发者，右键 → 打开 |
| Linux | `一键配置AI助手-Linux.sh` | 终端执行 `bash 一键配置AI助手-Linux.sh` |

脚本会自动完成：检测/安装 Ollama → 设置跨域授权（OLLAMA_ORIGINS）和监听地址（OLLAMA_HOST=0.0.0.0:11434）→ 启动服务 → 拉取默认模型 `qwen2.5:7b`（约 4-5 GB）→ 连通性测试 → 自动打开交易系统。默认模型可在脚本第一行的 `MODEL` 处修改（需与 `ollama list` 中的名称一致）。首次跑完之后，日常使用只需双击 `index.html`。

> **跑完一键脚本后如何验证 AI 是否正常？** 双击打开 `ai-self-test.html`，点「开始自检」即可一键验证连通性、模型列表、对话能力（4 步全绿即通过）。

### 方式二：手动配置（三步）

1. 到 `ollama.com` 下载安装并运行（桌面版或 `ollama serve`）。
2. 拉取一个中文模型，例如：`ollama pull qwen2.5:7b`（7B 级别即可，无需显卡也能跑）。
3. 因为本页以"本地文件"方式打开，需要允许跨域：
   - **Windows**：系统环境变量新增 `OLLAMA_ORIGINS`，值为 `*`，重启 Ollama；
   - **macOS**：终端执行 `launchctl setenv OLLAMA_ORIGINS "*"` 后重启 Ollama，或直接 `OLLAMA_ORIGINS="*" ollama serve`；
   - **Linux**：`OLLAMA_ORIGINS="*" ollama serve`。
4. 回到本系统「设置」→ 填地址 `http://localhost:11434` → 点「测试连接并列出模型」→ 保存。

> AI 没配置也完全不影响使用：规则评分引擎是纯本地逻辑，不依赖任何模型。

## 四、云端同步：电脑关机也能用（可选）

这是"电脑关机也能随时记账复盘"的答案：把系统部署到云端免费主机（或家里常开的小主机/树莓派），手机和电脑都连同一个云端地址，数据自动双向同步。

- **怎么部署**：跟着文件夹里的 **`部署指南.md`** 一步一步做（约 10 分钟，免费，全程网页点击操作）。
- **局域网模式**：不想上云，也可以在电脑上双击 `启动同步服务-xxx` 脚本，手机连**同一 WiFi** 浏览器打开电脑 IP 使用（适合家里电脑白天开着的情况）。
- **同步规则**：每次改动自动推送到云端；打开页面自动拉取。多设备各自改了不同记录会自动合并，同一条记录以**较新时间戳**为准。
- **防倒灌保护**：云端存在更新数据时，旧设备的数据不允许直接覆盖，避免旧手机把新数据冲掉。
- **安全**：部署时可设置访问令牌（TOKEN），没有令牌的人拿不到你的数据。
- **配置入口**：系统「设置」页最下方「云端同步」区块，填服务器地址和令牌，点「测试连接」→「保存并立即同步」即可。

## 五、手机上使用

界面已针对手机全面适配，两种入口任选：

1. **浏览器直接打开**（云端模式）：手机浏览器输入部署后的网址即可，界面自动切换为手机版。
2. **添加到主屏幕**（推荐）：手机浏览器打开后，用「添加到主屏幕 / 添加到桌面」，之后像 App 一样从桌面图标进入，全屏无地址栏。
   - iPhone（Safari）：分享按钮 → 添加到主屏幕
   - 安卓（Chrome）：右上角菜单 → 添加到主屏幕

手机版的专门优化：

- **底部标签栏**：总览/思想库/台账/复盘/问询/设置都在拇指可及的屏幕底部，单手可切换；
- **触控尺寸**：按钮、输入框、下拉都加大到适合手指点按的尺寸；输入框 16px 字号避免 iOS 聚焦时自动放大页面；
- **全屏弹窗**：记账、复盘等表单在手机上以全屏呈现，方便填写；
- **表格自适应**：持仓、交易列表在窄屏自动收纳次要信息，保证核心数据可读；
- **离线可用**：添加到主屏幕后，即使临时没网（如电梯、地铁），仍能打开查看已缓存的数据，联网后自动同步。

## 六、数据安全与备份（重要）

- 所有数据默认保存在**当前浏览器**的本地存储中：不上传、不联网（配置云端同步后才会上传到你自己的服务器）。
- 纯离线模式下，换浏览器、换电脑、清理浏览器数据会丢失数据。**请每周到「设置」导出一次 JSON 备份**。
- 换环境：旧环境导出 → 拷贝 JSON 文件 → 新环境「设置」→ 导入（替换模式）。
- 也可以直接拷贝整个 `stock-system` 文件夹到 U 盘，但数据本身在浏览器里，**文件夹里没有你的数据**，所以导出 JSON 才是真正的备份。
- 开启云端同步后，云端服务器会保留一份数据文件（`cloud-data.json`），相当于每天自动异地备份；仍建议保留每周导出 JSON 的习惯，双保险。
- 建议把导出的 JSON 同时存一份到网盘/U 盘/另一台电脑。

## 七、常见问题

| 问题 | 说明 |
|---|---|
| 为什么没有实时行情？ | 刻意不做联网行情：本系统的定位是纪律与复盘，不是看盘软件。持仓现价在「总览」手动填一次即可算市值与浮盈亏。 |
| 数据存在哪个文件里？ | 在浏览器 profile 的本地存储中，无法直接当文件拷贝，所以务必用「导出 JSON」做备份（开启云同步后云端也有副本）。 |
| 手机能用吗？ | 能，且已做手机专门适配：底部标签栏、触控尺寸、全屏表单。云端模式下手机浏览器打开网址，或「添加到主屏幕」当 App 用。 |
| 电脑关机了手机还能用吗？ | 部署了云端同步（见「部署指南.md」）就可以：数据在云端 24 小时在线。纯离线模式不行。 |
| 两台设备同时改数据会乱吗？ | 不会。不同记录自动合并；同一条记录以时间戳较新者为准，且旧数据不允许覆盖云端新数据。 |
| 演示数据是真实建议吗？ | 不是。示例中的股票、价格、规则均为演示用途，不构成任何投资建议。 |

```
├── icons/                  App 图标（192/512/苹果触屏图标）
├── js/
│   ├── store.js            数据层：存储、持仓/胜率/纪律统计、评分引擎
│   ├── sync.js             云端同步层：拉取/推送/多设备合并
│   ├── components.js       弹窗、确认框、提示条
│   ├── view-dashboard.js   总览
│   ├── view-principles.js  思想库（素材 + 规则版本）
│   ├── view-trades.js      交易台账
│   ├── view-review.js      复盘中心
│   ├── view-check.js       个股问询（评分引擎 + 本地AI）
│   ├── view-settings.js    设置（备份/导入/AI/云端同步）
│   └── app.js              导航路由
├── 一键配置AI助手-Windows/macOS/Linux   双击自动装 Ollama、拉模型、开授权并打开系统
├── 启动同步服务-Windows/macOS/Linux      局域网模式：电脑上双击，手机连同一 WiFi 访问
├── ai-self-test.html       AI 自检工具

```
